## Overview

Icinga is an open-source monitoring solution that checks the availability of network resources, notifies users of outages, and generates performance data for reporting. It is a fork of Nagios and written in C.

## Features

- Auto-discovery via plugin
- Agentless and agent-based monitoring
- SNMP, Syslog, and plugin support
- Trending
- Threshold triggers and alerts
- Full-control web application
- Distributed monitoring and inventory
- Access control and IPv6 support
- Network maps via plugin
- MariaDB, MySQL, PostgreSQL data storage
