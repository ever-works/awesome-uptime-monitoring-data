## Overview

Netdisco is an open-source network management platform that provides network discovery, inventory, and monitoring. It is written in Perl and uses PostgreSQL as its data store.

## Features

- Auto-discovery of hosts and network devices
- Agentless monitoring
- SNMP, Syslog, and plugin support
- Triggers and alerts
- Web application
- Distributed monitoring and inventory
- Access control and IPv6 support
- Network maps
- PostgreSQL data storage
