## Overview

Performance Co-Pilot (PCP) is an open-source framework for system-level performance monitoring and analysis. It collects performance metrics from systems and archives them for analysis.

## Features

- Plugin-based architecture
- Triggers and alerts
- Web-based viewing frontend
- Distributed monitoring and inventory
- Access control and IPv6 support
- Flat file data storage
- Optional agent support
