## Overview

InterMapper is a network monitoring and network mapping tool that automatically discovers network devices and monitors their status. It is developed by HelpSystems and runs on Windows, Linux, and macOS.

## Features

- Auto-discovery of hosts and network devices
- Agentless monitoring
- SNMP, Syslog, and plugin support
- Trending
- Threshold triggers and alerts
- Viewing web application
- Distributed monitoring and inventory
- Access control and IPv6 support
- Network maps
- PostgreSQL data storage

## Pricing

Limited free edition available; commercial licensing for full features.
