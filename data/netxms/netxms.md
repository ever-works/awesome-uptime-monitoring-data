## Overview

NetXMS is an open-source network management and monitoring system that provides monitoring, graphing, alerting, and reporting for IT infrastructure. It is written in C and Java.

## Features

- Auto-discovery of hosts and network devices
- Agentless monitoring
- SNMP, Syslog, and plugin support
- Triggers and alerts
- MIB compiler
- Web application
- Distributed monitoring and inventory
- Access control and IPv6 support
- Network maps
- Multi-database support: PostgreSQL, TimescaleDB, MariaDB, MySQL, MS SQL, Oracle, SQLite
