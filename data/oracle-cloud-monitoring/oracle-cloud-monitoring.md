## Overview

Oracle Cloud Monitoring is part of Oracle Cloud Infrastructure's always-free services. It allows users to monitor the health and performance of their cloud resources by collecting and retrieving monitoring datapoints.

## Free Tier

- 500 million ingestion data points per month
- 1 billion retrieval datapoints per month
