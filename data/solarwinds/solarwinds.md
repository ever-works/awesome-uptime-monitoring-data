## Overview

SolarWinds is a commercial IT management software company that provides network monitoring, IT infrastructure management, and observability tools. Its platform is written in .NET and uses SQL data storage.

## Features

- Auto-discovery of hosts and network devices
- Partial agentless monitoring
- SNMP, Syslog, and plugin support
- Trending and trend prediction
- Threshold triggers and alerts
- Full-control web application
- Distributed monitoring and inventory
- Access control and IPv6 support
- Network maps
- SQL data storage
