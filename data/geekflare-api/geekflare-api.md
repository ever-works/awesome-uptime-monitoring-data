## Overview

Geekflare API provides website monitoring capabilities including scraping, screenshots, TLS scans, DNS lookups, and load time testing.

## Features

- Scrape websites into Markdown
- Take screenshots
- Perform TLS scans and DNS lookups
- Test load times

## Pricing

Free plan offers 500 API credits per month (e.g., 500 DNS lookups, 250 web scrapes, or 100 screenshots).
