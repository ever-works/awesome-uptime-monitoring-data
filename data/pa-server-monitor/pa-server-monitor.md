## Overview

PA Server Monitor is a server monitoring tool for Windows environments that monitors servers, applications, and network devices. It is written in C++ and .NET.

## Features

- Auto-discovery of hosts and network devices
- Agentless monitoring
- SNMP, Syslog, and plugin support
- Trending and trend prediction
- Threshold triggers and alerts
- Web application for viewing, acknowledging, and reporting
- Distributed monitoring and inventory
- Access control and IPv6 support
- Network maps
- SQLite, Microsoft SQL Server data storage

Limited free edition available; commercial licensing for full features.
