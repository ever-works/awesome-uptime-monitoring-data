## Overview

Xymon is an open-source monitoring system for hosts and networks, originally developed as Hobbit. It is written in C and Shell and provides real-time monitoring, alerting, and historical data graphing.

## Features

- Auto-discovery via plugin
- Plugin-based monitoring
- SNMP via plugin
- Threshold triggers and alerts
- Web application for viewing, acknowledging, and reporting
- Distributed monitoring and inventory
- Apache access control
- Network maps via plugin
- Flat file, RRDTool, MySQL (via plugin) data storage
