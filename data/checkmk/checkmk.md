## Overview

Checkmk is an open-source monitoring platform for infrastructure, applications, and networks. It is written in C and Python and uses RRDtool for storing performance data.

## Features

- Auto-discovery of hosts and network devices
- Agentless and agent-based monitoring
- SNMP, Syslog, and plugin support
- Trending and trend prediction
- Threshold triggers and alerts
- Full-control web application
- Distributed monitoring and inventory
- Access control and IPv6 support
- Network maps
