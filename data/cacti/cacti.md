## Overview

Cacti is an open-source network monitoring and graphing solution designed to collect time-series data and render network performance graphs.

## Features

- SNMP-based polling for network devices
- RRDtool, MySQL, and MariaDB data storage backends
- Logical grouping of hosts and devices
- Trending and trend prediction
- Auto-discovery of hosts
- Agentless operation
- Syslog and plugin support
- Threshold triggers and alerts
- Full-control web application
- Distributed monitoring and inventory tracking
- Access control and IPv6 support
- Network maps via plugin
