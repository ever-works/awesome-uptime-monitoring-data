## Overview

CronAlive provides heartbeat monitoring for cron jobs, plus HTTP uptime and TLS expiry checks. Includes a Laravel package that creates checks from your scheduler.

## Features

- Heartbeat monitoring for cron jobs
- HTTP uptime checks
- TLS expiry checks
- Laravel package for scheduler integration
- 10 checks (free tier)
- HTTP interval from 5 min
- 30 days of history
- 50k pings/mo
