## Overview

collectd is an open-source Unix daemon that collects, transfers, and stores performance data from computers and network devices.

## Features

- Push model with optional multicast
- SNMP and syslog support
- Plugin-based architecture
- Triggers and alerts
- Web-based viewing frontend
- RRDtool data storage
- Apache access control
- IPv6 support
