## Overview

OpenNMS is an open-source enterprise-grade network monitoring and management platform. It is written in Java and provides fault management, performance monitoring, and event management for networks and IT infrastructure.

## Features

- Auto-discovery of hosts and network devices
- Agentless monitoring
- SNMP, Syslog, and plugin support
- Trending and trend prediction
- Threshold triggers and alerts
- MIB compiler
- Full-control web application
- Distributed monitoring and inventory
- Access control and IPv6 support
- Network maps
- JRobin / RRDTool / Apache Cassandra, PostgreSQL data storage
