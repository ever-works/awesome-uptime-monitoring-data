## Overview

Pandora FMS is a flexible monitoring system that monitors IT infrastructure, applications, and business processes. It is written in Perl, PHP, C++, and JavaScript and uses MySQL as its data store.

## Features

- Auto-discovery of hosts and network devices
- Agentless monitoring
- SNMP, Syslog, and plugin support
- Trending and trend prediction
- Threshold triggers and alerts
- Full-control web application
- Distributed monitoring and inventory
- Access control and IPv6 support
- Network maps
- MySQL, Percona Server for MySQL data storage
