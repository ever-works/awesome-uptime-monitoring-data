## Overview

PRTG Network Monitor is an agentless network monitoring software that monitors IT infrastructure, bandwidth, and applications using SNMP, WMI, and other protocols. It is developed by Paessler and written in Delphi.

## Features

- Auto-discovery of hosts and network devices
- Agentless monitoring
- SNMP, Syslog, and plugin support
- Trending
- Threshold triggers and alerts
- MIB compiler
- Full-control web application
- Distributed monitoring and inventory
- Access control and IPv6 support
- Network maps
- Flat file data storage

## Pricing

Limited free edition available (up to 100 sensors); commercial licensing for full features.
