## Overview

Checkmate is an open-source, self-hosted monitoring tool built with React.js, Node.js, and MongoDB.

## Features

- Track server uptime, response times, and incidents in real-time
- Modern UI
- E-mail, Webhook, Discord and Slack notifications
- Multi-language frontend

## Pricing

Free and open-source.
