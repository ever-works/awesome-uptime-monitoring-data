## Overview

Ganglia is an open-source distributed monitoring system designed for clusters and grids. It monitors hundreds to thousands of nodes in real time using a hierarchical design.

## Features

- Scalable distributed monitoring
- Logical grouping of hosts
- Trending of network data over time
- Plugin support
- Triggers and alerts
- Web-based viewing frontend
- RRDtool data storage
- Network maps
- IPv6 support with unknown status
