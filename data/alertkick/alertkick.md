## Overview

AlertKick is a server security and uptime monitoring product combining eBPF agent for Linux with uptime monitoring, on-call alerting, and status pages.

## Features

- Server security (eBPF agent for Linux)
- Uptime monitoring
- On-call alerting
- Status pages
- 10 uptime monitors and heartbeats (free tier)
- 5-minute check intervals
- 7-day retention

Free tier available.
